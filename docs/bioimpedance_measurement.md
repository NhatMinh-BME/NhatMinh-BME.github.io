# Bioimpedance Measurement Systems

This work covers several bioimpedance measurement prototypes for applications including body impedance analysis, electrical impedance tomography, and epithelial electrical resistance.

## Technical work

- An ESP32-S3 design using the Analog Devices AD5941 analog front end
- An STM32H7 design using a third-party impedance-measurement front end
- C++ firmware, FreeRTOS integration, and signal-processing routines
- A discrete Fourier transform (DFT) implementation for real-time impedance calculation
