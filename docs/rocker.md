# Rocker Shaker Machine

A laboratory rocker-shaker project commissioned by a biotechnology startup. The work brought together embedded control, motor and mechanical design, and prototype testing.

## Project focus

The design uses an ESP32-S3 with C++ firmware and an RTOS. The project requirements covered:

- Stepper-driven rocking motion with controlled speed and position
- Motor-driver, sensor, and user-interface integration
- Wireless connectivity for monitoring and control
- A stable, manufacturable platform for different laboratory vessels
- Operator controls and protective features, including emergency stop and fault handling

These are design requirements; this page does not claim certification to a laboratory safety standard.
