# Tools

Small utilities I built or adapted for hardware and measurement work.

## Utilities

- [PT5 Reader](./pt5reader.md) — read Monsoon Power Monitor `.pt5` capture files, export them to CSV and inspect device info.
- [AMS1117 Efficiency Calculator](/ams_1117_efficiency_calculator.html) — estimate the efficiency and heat dissipation of an AMS1117 linear regulator.
