# Project Template

Copy this template for each project and replace the bracketed text. Remove any sections that do not apply, and only publish claims and images you can share.

```markdown
## [Project title]

**Status:** [In progress / Completed]\
**Date:** [Month YYYY or YYYY–YYYY]\
**My role:** [Your role]\
**Team or organization:** [Optional]

### Overview
[In 2–4 sentences, describe the problem, who it affects, and what the project does.]

### My contributions
- [What you personally designed, implemented, tested, or led]
- [A second specific contribution]
- [A measurable result, if you have one and can substantiate it]

### Tools and methods
[Technologies, methods, equipment, or software you used]

### Outcome and lessons
[What was delivered, what you learned, and any limitations worth noting.]

### Links
- [Demo, repository, paper, or public project page](https://example.com)

![Short description of the image](/images/your-project-image.jpg)
```

Put images you have permission to publish in `docs/public/images/`. Reference them with a path beginning `/images/`.
